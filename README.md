# Online Retail Customer Analytics & Segmentation

## Project Overview

This project applies statistical analysis and customer analytics techniques to an online retail transaction dataset to understand customer purchasing behaviour, identify high-value customer groups, and generate data-driven business recommendations.

## Business Problem

An online retailer needs to better understand its customers in order to improve customer targeting, retention, and commercial decision-making.

The analysis focuses on identifying differences in customer purchasing behaviour, understanding factors associated with customer value, and developing meaningful customer segments.

## Objectives

- Analyse customer purchasing behaviour using descriptive and exploratory statistics.
- Identify high-value customers and customer groups.
- Test important business hypotheses using appropriate statistical methods.
- Examine relationships between customer behaviour and monetary value.
- Develop customer segments using data-driven techniques.
- Translate statistical findings into actionable business recommendations.

## Dataset

The analysis uses the publicly available **UCI Online Retail dataset**.

Source: UCI Machine Learning Repository

The dataset contains transaction-level records from a UK-based online retailer.

## Analytical Approach

The project will follow a structured business analytics workflow:

Business Problem → Data Understanding → Data Quality → Data Cleaning → EDA → Hypothesis Testing → Statistical Analysis → Customer Value Analysis → Segmentation → Business Recommendations
